# weissens.ee

The events calendar for Berlin-Weißensee, an instance of
[openLitfass](https://github.com/schreibtischhelden/openlitfass).

This repository contains only content and styling. Code, front end and
container image come from the core repository (instance layout: see
[Setting up an instance](https://docs.openlitfass.org/?page=setup)
there).

| File/folder | Contents |
|---|---|
| `instance.json` | name, title, time zone, base URL |
| `sources/` | event sources (active: Familienzentrum, Brotfabrik, Freilichtbühne, Stadtteilzentrum, Peter Edel, KuBiZ, Kino Toni, Theater im Delphi, Schnurre-Bibliothek, Kunsthochschule; see [docs/sources-checklist.md](docs/sources-checklist.md)) |
| `inbox/` | individual events added by hand |
| `categories.json` | categories and icons |
| `site/` | theme (lake-blue petrol and brick), logo |
| `data/` | generated by `fetch` (real events, as of the last run) |
| `docs/` | source checklist, source research, collection of places, colour system (`docs/media/`) |

## Documentation

## Running locally

In the folder of this repository, with a locally built or pulled core image:

```sh
docker run -d --name weissens --restart unless-stopped -v "$PWD:/instance" -p 8080:8080 \
  -e OL_STATIC_PAGES=true -e OL_SITEMAP_GENERATOR=true openlitfass
```

Then open <http://localhost:8080>. The container fetches all sources every six
hours and rebuilds the site; its state is available at
<http://localhost:8080/healthz>. While running, it writes to `data/` and the
`status` fields in `sources/`, and deletes expired `inbox/` files; commit
these changes as needed. Details:
[Operation](https://docs.openlitfass.org/?page=setup#run-as-a-container)
in the core documentation.

weissens.ee uses both of the core's SEO features (which are disabled by
default): `OL_STATIC_PAGES` (static event pages under `termine/`, today's
events already in the HTML of the start page) and `OL_SITEMAP_GENERATOR`
(`sitemap.xml`, `robots.txt`). The same settings are used in the workflow
`.github/workflows/update-events.yml`.

## Publishing

The workflow [`.github/workflows/update-events.yml`](.github/workflows/update-events.yml)
builds the site every six hours and writes it to the `pages` branch (GitHub
Pages, domain `weissens.ee` via `CNAME`). For the DNS set-up, see
[GitHub Pages with a custom domain](https://docs.openlitfass.org/?page=github-pages).
